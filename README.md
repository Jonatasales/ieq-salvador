# IEQ Salvador — Projeto de Vida 2027

Landing estática da Igreja do Evangelho Quadrangular Salvador.

- Site: `site/`
- Publicação: `netlify.toml` aponta o publish para `site/` (sem build).
- Domínio previsto: `https://www.ieqsalvador.com.br/`

## Abrir localmente

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory site
```

Abra `http://127.0.0.1:4173/`.
